# Хранение: Iron Chests, JABBA, Storage Drawers, EnderStorage — большие сундуки, бочки и ящики на один предмет, общие сундуки Края

## Что выбрать
- Много РАЗНЫХ предметов → сундуки Iron Chests.
- Очень много ОДНОГО предмета (булыжник, руда, слитки) → Ящик (Storage Drawers) или Better Barrel (JABBA).
- Доступ к вещам из разных мест/измерений, общий склад с друзьями → Сундук Края (EnderStorage).
- Позже всё сводится в сеть AE2 или Logistics Pipes — они читают все эти хранилища.

## Iron Chests 6.0.62
- Сундуки по слотам: Медный сундук 45, Железный сундук 54, Серебряный сундук 72, Золотой сундук 81, Алмазный сундук 108, Кристальный сундук 108 (прозрачный — видно содержимое), Обсидиановый сундук 108 (устойчив к взрывам). DirtChest 9000! — шуточный.
- Не объединяются в двойные — ставь рядом сколько нужно.
- Улучшение на месте, не вынимая вещи: ПКМ предметом-улучшением по стоящему сундуку. Цепочки: из деревянного в железный/медный; из медного в железный/серебряный; из железного в золотой; из серебряного в золотой; из золотого в алмазный; из алмазного в кристальный или обсидиановый (например «Улучшение из деревянного в железный сундук»).
- Медь и серебро — слитки любого мода по словарю руд (IC2, Thermal Foundation).

## JABBA 1.2.2 (Better Barrels)
- Better Barrel (так называется в игре) хранит ОДИН вид предмета, базово 64 стака.
- Управление: ПКМ — положить стак, двойной ПКМ — положить все такие из инвентаря; ЛКМ — взять стак, Shift+ЛКМ — один предмет.
- Улучшения: сначала структурное «Структурный MK» (уровни до 7 крафтом) даёт слоты улучшений; затем основные: Улучшение хранилища (x3 … x243 — каждое +стаки, занимает слоты), Пространственное улучшение (связывает бочки, нужен Пространственный камертон — общий запас в нескольких бочках), Красное улучшение (сигнал по заполненности), Загрузочное улучшение (бочка сама выталкивает в соседние инвентари), Пустотное улучшение (лишнее уничтожается — для автоферм). Боковые: Наклейка (показывает содержимое на стороне), Загрузочный фасад, Красный фасад (требуют соответствующего основного улучшения).
- Снять улучшения — Бочкообразный молот (режимы: Хранилищный, Структурный, Резонирующий и т.д.).
- Тележка — переносит сундуки/бочки с содержимым; Алмазная тележка — ещё и спавнеры (на сервере включено).

## Storage Drawers 1.10.9
- Ящик (1×1) — 32 стака одного предмета; Ящик … 1x2 — 2 отсека по 16 стаков; Ящик … 2x2 — 4 по 8; Компактный ящик 1x2 — по 8; Компактный ящик 2x2 — по 4 (это значения сервера). Делаются из любого дерева.
- Управление: ПКМ — положить, двойной ПКМ — положить все такие; ЛКМ — взять стак, Shift+ЛКМ — один.
- Улучшение хранилища (II) ×2, (III) ×3, (IV) ×5, (V) ×8, (VI) ×13 к ёмкости (вставляются в интерфейс ящика; основа — Шаблон улучшения). Не путать с «Улучшение хранилища» JABBA.
- Уплотняющий ящик — сам переводит самородки ↔ слитки ↔ блоки (и т.п. 9:1), показывает все три формы.
- Ключ от ящика — закрепляет предмет за отсеком даже когда пусто (для сортировки). Пустотное улучшение — уничтожает лишнее. Улучшение «Индикатор» (I/II) — показывает заполненность.
- Контроллер ящиков — один вход/выход для всех ящиков в радиусе 12 блоков, соединённых вплотную (Подчинённый контроллера — доп. точки доступа, Отделка — соединитель-декор). Трубы, узлы ExtraUtilities, туртлы кидают в контроллер — он раскладывает по ящикам.
- AE2: МЭ шина хранения на ящик/контроллер — ящики становятся частью сети (интеграция включена). Waila показывает содержимое.

## EnderStorage 1.4.7
- Сундук Края (27 слотов), Цистерна Края (жидкость), Сумка Края (переносной доступ).
- Частота — три цвета на крышке: ПКМ красителем по цветной метке. Все сундуки/цистерны с одинаковыми цветами — ОДНО содержимое, в любом месте и измерении.
- Личный: ПКМ Алмаз по защёлке — частота становится твоей (другие игроки с теми же цветами не видят). Без этого любой игрок, угадавший цвета, получает доступ!
- Сумка Края: Shift+ПКМ по сундуку — перенимает его цвета.
- Применение: туртл/карьер Края кладёт добычу в Сундук Края далеко от базы, а дома такой же сундук вынимается трубой.

## Частые ошибки
- Публичный Сундук Края с простыми цветами — его содержимое доступно всем.
- Ломают полный Better Barrel/Ящик с тысячами предметов — перед этим опустоши, бочку переноси Тележка.
- Пытаются сделать двойной Железный сундук — так нельзя.
