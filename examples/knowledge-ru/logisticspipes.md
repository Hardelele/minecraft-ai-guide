# Logistics Pipes 0.9 — «умные» трубы поверх BuildCraft: заказ предметов, автокрафт по запросу, сортировка и снабжение

## Что это и зачем
- Надстройка над трубами BuildCraft: каждая логистическая труба — узел сети, который знает, где что лежит и куда что нужно. Предметы едут по обычным трубам BC, но сами находят адресата.
- Что умеет: заказать предмет из всех сундуков сети в одно окно; автоматически скрафтить недостающее (в т.ч. цепочкой и через машины); держать сундук/машину заполненными; сортировать всё, что приходит.
- Требует BuildCraft (трубы BC — «провода» между логистическими трубами). Альтернатива по задачам — сеть AE2; LP дешевле на старте, AE2 компактнее.
- Точные рецепты — инструментом рецептов.

## Основа сети
- Логистические трубы соединяются напрямую или через обычные транспортные трубы BC (до ~50 труб BC между двумя логистическими — ограничение конфига сервера). Развилки из обычных труб работают хуже — лучше линия.
- Энергия обязательна (на сервере включена): Логистическое энергетическое хранилище ставится вплотную к любой логистической трубе и принимает RF (TE, EnderIO, BC…) и EU (IC2). Без энергии сеть стоит.
- Связь «сеть — сундук/машина» делает труба, прижатая к инвентарю.

## Главные трубы
- Основная логистическая труба — приёмник: в настройках перечисляешь предметы, которые она принимает в свой сундук. Одну можно сделать «направлением по умолчанию» — туда пойдёт всё, что больше никуда не подходит.
- Логистическая труба-провайдер (Mk2) — отдаёт содержимое прижатого сундука по запросам сети (Mk1 — по 16 штук, Mk2 — стаками).
- Логистическая труба запросов / Логистическая труба запросов Mk2 — окно заказа: видишь все предметы сети, заказываешь, предметы приходят в сундук на этой трубе. Логистический стол запросов — то же блоком, с сеткой крафта.
- Логистическая труба создания (Mk1 — по одному, Mk2 — по 16, Mk3 — стак) — прижимается к Логистический верстак, Автоматический верстак BC или машине; в ней задаётся рецепт; при заказе сеть сама шлёт ингредиенты и забирает результат. Крафты цепляются друг за друга (рекурсивно).
- Вспомогательная логистическая труба — второй пункт доставки для трубы создания (когда часть ингредиентов надо отправить в другую машину/сторону); связываются одинаковым номером.
- Логистическая труба снабжения — держит прижатый сундук или машину заполненными заданными предметами (например, топливо в генератор).
- Логистическое шасси Mk1…Mk5 — труба с 1/2/3/4/8 слотами под модули; ставится у инвентаря, сторону к инвентарю выбирают Гаечный ключ. Модули: ItemSink модуль (приёмник по списку), Полиморфный ItemSink модуль (принимает то, что уже лежит), OreDict ItemSink модуль, Модовый ItemSink модуль, Модуль извлечения (MK2/MK3 быстрее; Продвинутый — с фильтром) — вытягивает в сеть, Модуль поставки, Пассивный модуль снабжения / Активный модуль снабжения, Модуль быстрой сортировки, Модуль создания (MK2/MK3), Конечный модуль.
- Жидкости: Логистическая жидкостная труба-провайдер / запросов / вводящая / извлекающая / снабжения / вспомогательная — те же роли для жидкостей.
- Связь сетей: Логистический инвентарный системный коннектор (две сети через общий инвентарь, обычно Сундук Края), Логистическая брандмауэрная труба (пропускает только нужное), Логистическая системная входная труба + Логистическая системная труба назначения (пара, связанная частотной картой). Логистическая труба дистанционных запросов + Удалённый запросчик — заказ издалека.

## Блоки и улучшения
- Логистический верстак (и Логистический нечёткий верстак — принимает эквиваленты по словарю руд) — верстак для трубы создания, тратит энергию LP на крафт.
- Паяльная станция — делает часть деталей и улучшений LP. Логистическая станция безопасности — права игроков и доступ ComputerCraft. Логистический стол статистики.
- Улучшения ставятся в слоты улучшений трубы (удобно через Менеджер улучшений): Улучшение «Скорость предметов»; Скрытое улучшение (ВЕРХ/НИЗ/…) — класть в машину с нужной стороны (важно для машин с разными входами); Разъединяющее улучшение — отключить сторону; Улучшение «Нечёткое создание» — рецепт принимает эквиваленты по словарю руд; Улучшение «Извлечение побочного продукта», Улучшение «Создание жидкостей», Продвинутое вспомогательное улучшение.
- Энергия машинам от сети: Логистический провайдер RF-энергии / Логистический провайдер EU-энергии + Улучшение «Снабжение TE-энергией» / «Снабжение энергией НН IC2» (СН, ВН, СВН) в трубе — труба питает прижатую машину из энергии LP.
- Логистический интерфейс очков — HUD с содержимым сети. ComputerCraft 1.75: трубами можно управлять с компьютера (Улучшение «Удалённый CC-контроль», CC-модули).

## С чего начать
1. Проложить трубы BC между сундуками, поставить Логистическое энергетическое хранилище и подать RF.
2. На каждый склад-сундук — Логистическая труба-провайдер; на сундук «для всего прочего» — Основная логистическая труба как направление по умолчанию.
3. Логистическая труба запросов + сундук на ней — первая точка заказа.
4. Вход в сеть (добыча, фермы): Логистическое шасси с Модуль извлечения — всё уедет по провайдерам/приёмникам.
5. Автокрафт: Логистический верстак + Логистическая труба создания с рецептом; для машин — труба создания у машины (+ Вспомогательная логистическая труба при нескольких входах).

## Частые ошибки
- Сеть не реагирует — нет энергии в Логистическое энергетическое хранилище или оно не касается логистической трубы.
- Предметы «некуда девать» — нет приёмника/направления по умолчанию; предмет может выпасть из трубы (выпавшие из труб BC исчезают через 60 с).
- Шасси смотрит не на тот инвентарь — повернуть Гаечный ключ.
- Крафт через машину не завершается — результат должен вернуться в сеть (автовыгрузка машины в трубу или Модуль извлечения), а ингредиенты — попасть в нужный слот (Скрытое улучшение с нужной стороной).
- Слишком длинные участки обычных труб BC между логистическими (> 50) — трубы «не видят» друг друга.

## Стыковка с другими модами сборки
- Энергия сети: RF от Thermal Expansion / EnderIO / BuildCraft / ExtraUtilities или EU от IC2 (хранилище принимает оба).
- Работает с любыми инвентарями: машины TE/EnderIO/IC2/MFR, сундуки Iron Chests, JABBA, Storage Drawers, Сундук Края (EnderStorage — для связи сетей на расстоянии).
- Трубы создания у машин TE (Индукционная плавильня, Измельчитель и др.) позволяют заказывать то, что делается в машинах, — так можно автоматизировать и шаги цепочки SiliconFab (чипы AE2 и схемы IC2), шаг за шагом.
- ComputerCraft: LP-трубы — периферия для компьютеров.
- Металлы разных модов (медь TF и IC2 и т.п.): в обычном верстаке их подменяет ModGlue; в трубе создания эквиваленты по словарю руд включает Улучшение «Нечёткое создание» или Логистический нечёткий верстак.
