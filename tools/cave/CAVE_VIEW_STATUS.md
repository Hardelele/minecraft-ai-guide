This is an isolated Commander prototype. It has not passed the requested multi-level visual gate.

- Select one underground agent in Commander. `C` switches between the existing one-level `U` view and a connected 3D air-volume view. `Q/E` orbit; the wheel zooms. The map is anchored at the air cell selected when `C` opens it; moving into a separate pocket does not silently replace the mapped component. Close and reopen with `C` to choose a new component. Only currently loaded chunks are sampled.
- The 3D view traverses 6-connected open cells in XYZ. Walls, floors and faint ceilings use actual exposed block faces; sealed ore has no face in the connected component. It re-renders entities in that component and blocks world clicks because vanilla picking still sees the uncut terrain. It never passes geometry or ore to the planner.
- Work is limited to radius 28, at most 12,000 air cells and 8,000 faces, scanning 400 cells per game tick. The UI marks a partial result. “Open top” means an air connection upward, not a walkable agent route. A changed block near the selected agent triggers an update from the fixed seed; other edits may take up to 40 ticks to appear. A blocked seed can show the last valid shell for at most 80 world ticks with an explicit old-view label, then the map becomes unavailable.
- When that same agent reaches the surface, the underground volume stays visible until `C` is pressed or a different agent is chosen. The camera stays at the mapped anchor; the actor is omitted after leaving the displayed component and the UI says so. Closing the view recenters on the surfaced agent. Surface detection uses the heightmap and may classify a shallow roof early.
