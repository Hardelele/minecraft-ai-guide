# Connected cave view prototype — NEW REVISION UNVERIFIED_RUNTIME

This is an isolated Commander prototype. It has not passed the requested multi-level visual gate.

- Select one underground agent in Commander. `C` switches between the existing one-level `U` view and a connected 3D air-volume view. `Q/E` orbit; the wheel zooms. The view follows the selected agent and shows only currently loaded chunks.
- The 3D view traverses 6-connected open cells in XYZ. Walls, floors and faint ceilings use actual exposed block faces; sealed ore has no face in the connected component. It re-renders entities in that component and blocks world clicks because vanilla picking still sees the uncut terrain. It never passes geometry or ore to the planner.
- Work is limited to radius 28, at most 12,000 air cells and 8,000 faces, scanning 400 cells per game tick. The UI marks a partial result. “Open top” means an air connection upward, not a walkable agent route. A changed block near the selected agent triggers an update; farther edits may take up to 40 ticks to appear. A transient invalid air probe can show the last valid shell for at most 80 world ticks with an explicit old-view label.
- When that same agent reaches the surface, the underground volume stays visible until `C` is pressed or a different agent is chosen. The model and camera are frozen at their last underground position during this transition; the actor is omitted after leaving the displayed component. Closing the view recenters on the surfaced agent. Surface detection uses the heightmap and may classify a shallow roof early.
